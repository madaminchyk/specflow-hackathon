# Реальные снимки интерфейса

`desktop.png` (1440×900) и `tablet.png` (768×1024) получены Playwright в первом браузерном прогоне и визуально просмотрены. Показывают рабочую поверхность учебного проекта. Это не свидетельство успешного полного e2e: сценарий редактирования был прерван перезагрузкой интерфейса во время разработки. Повторный браузерный прогон не разрешён в текущей сессии.

Снимка 360×800 пока нет. При разрешённом успешном запуске `npm run test:e2e` тест сохранит актуальные снимки всех трёх размеров в эту папку. Тестовые артефакты с трассами находятся в игнорируемой git папке `test-results/`.
