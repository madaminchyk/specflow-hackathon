Всего **40 успешных тестов** в двух целевых прогонах:

```sh
npm test -- tests/provider.test.ts tests/audio.test.ts tests/http.test.ts tests/domain.test.ts tests/components.test.tsx
npm test -- tests/workspace-ai.test.tsx
```

Песочница Windows заблокировала первый запуск сборки на `spawn EPERM`; повторная разрешённая сборка вне песочницы прошла. Тесты запускались с разрешением на дочерний процесс esbuild. Сетевые проверки и e2e к этим командам не добавлялись.

WAV- и Ogg-фикстуры синтетические, предназначены для проверки контейнера и mock-запроса, а не качества распознавания речи. SpeechKit v1 возвращает текст без выравнивания по словам: приложение сохраняет один сегмент с приблизительным временем. Async-контракт подготовлен, но worker, Object Storage и polling ещё не реализованы; предел 30 секунд / 1 МБ не обходится.

Отчёт первоначального MVP сохранён отдельно в [VALIDATION](VALIDATION.md); его результаты прежнего провайдера не считаются результатами Yandex.
