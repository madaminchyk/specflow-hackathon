# Демонстрация SpecFlow — 3–4 минуты

Перед показом: `npm ci`, `npm run dev`, открыть адрес сервера. Один раз открыть приложение, чтобы браузер сохранил оболочку для офлайн-демо. Использовать отдельный профиль браузера. Подготовить экран 1440×900 и телефон. API-ключ не нужен. Демо — подготовленная учебная встреча, это нужно произнести вслух.

## 0:00–0:30 — проблема и запуск

«После встречи специалист вручную превращает разговор в техническое задание. Мы сокращаем эту работу и сохраняем основание каждого решения». Нажать **Открыть демо за 30 секунд**. Встреча о бронировании переговорных уже заполнена: 28 реплик, 18 элементов, две роли и три сценария.

## 0:30–1:20 — проверка источника

Выбрать «Вход через корпоративную учётную запись». Открыть **След требования**, нажать на источник 00:34. Слева выделится точная реплика заказчика. Показать описание и предложенный критерий приёмки. «Цитаты берутся из исходных сегментов, модель не сочиняет цитату или таймкод». В учебной встрече нет аудиозаписи: не изображать воспроизведение. Для демонстрации настоящего плеера заранее приложить свою запись и соответствующий SRT.

## 1:20–2:00 — спорное правило

Открыть **Противоречия**. Сравнить реплики про 30 и 14 дней. «Последняя фраза сама по себе не означает согласование. Решение принимает аналитик». Ввести «Для пилота согласовано 14 дней; правило 30 дней отклонено», нажать **Решено**. Затем открыть требование про 30 дней и поставить статус **Отклонено**. Это отдельное действие: решение конфликта не переписывает требования автоматически.

## 2:00–2:50 — редактирование и качество

Открыть **Вопросы**, показать три вопроса для следующей встречи. В требовании изменить описание, приоритет и статус, сохранить. Обновить страницу: правка сохраняется. Показать Quality Gate и формулу. «Это комплектность документа, а не измеренная точность AI». При желании удалить элемент и восстановить его кнопкой в уведомлении.

## 2:50–3:30 — результат

Открыть экспорт. Скачать Markdown или DOCX. Показать роли, сценарии, критерии и матрицу трассировки. «Каждый пункт можно проверить по разговору, а документ требует утверждения человеком». На телефоне переключить вкладки **Транскрипция**, **Требования**, **Инспектор**.

## 3:30–4:00 — честные ограничения

Демо и разбор текста работают без сети и ключа. Реальное распознавание подключается через серверный Yandex SpeechKit, анализ — через Yandex AI Studio; ключ хранится только на сервере. Синхронное аудио ограничено 30 секундами и 1 МБ. SpeechKit v1 не возвращает таймкоды слов, поэтому облачный результат помечен приблизительным временем. Локальные проекты принадлежат этому браузеру. Совместная работа, фоновая обработка больших записей и SSO входят в следующий этап.

Запасной сценарий: при недоступности сети открыть уже загруженное демо. При повреждении хранилища скачать резервную копию через экран проектов, очистить данные приложения и создать новое демо. Не использовать реальные приватные встречи на публичном показе.
