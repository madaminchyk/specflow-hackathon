## Что не считать подтверждённым

Пять дополнительных тестов, полный e2e, настоящий DOCX-download в браузере, проигрывание реального медиа с SRT, печать/PDF, installability PWA, offline-reload и runtime WebMCP в поддерживающем браузере требуют следующего разрешённого прогона. Snapshot-тестирование WebMCP использует mock контекста, а не нативную реализацию браузера. Исходники этих проверок готовы, но успешный результат не заявляется.

Зависимости при установке сообщили о двух уязвимостях умеренной важности. Детальный `npm audit --omit=dev` не запускался: запрос сетевого разрешения отклонён. Не выполнены автоматические обновления с возможными breaking changes. Перед публичным развёртыванием команда должна изучить полный audit и обновить зависимости адресно.

## Причины ограничений среды

Песочница Windows блокирует запуск дочернего процесса esbuild (`spawn EPERM`), поэтому Vitest/Vite и браузерные проверки требуют отдельного разрешения на выполнение. Первый build и 23 теста были разрешены и прошли. Повторный браузерный прогон, сетевой audit и запуск добавленных тестов не получили разрешения; отказ не обходился другими инструментами.

## Следующий воспроизводимый прогон

Остановите редактирование исходников на время e2e, чтобы HMR не сбрасывал открытые формы.

```powershell
npm run format:check
npm run typecheck
npm run lint
npm test
npm run build
$env:PLAYWRIGHT_CHANNEL='msedge'
npm run test:e2e
```

Если Edge не установлен, используйте `npx playwright install chromium` и уберите `PLAYWRIGHT_CHANNEL`. Сборка и тесты не требуют OpenAI-ключа. Для тестирования реального провайдера отдельно настройте `.env` и запустите `npm run dev:api`.
